# Amazon Clone

A simple Amazon clone website built using HTML and CSS. I built this project as a showcase of my web development skills after learning the basics of HTML and CSS.

## Features

* Amazon-inspired navigation bar
* Search bar and navigation sections
* Product and category sections
* Responsive layout
* Styled buttons and UI elements
* Footer section

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Media Queries

## Project Structure

```text
amazon-clone/
│
├── index.html

└── README.md
```

## About the Project

I built this project to put the HTML and CSS concepts I learned into practice and get more comfortable with creating a website from scratch.

I plan to continue developing this project by using JavaScript to add more interactive features and improve its responsiveness.
